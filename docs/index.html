About

Marketing, development, and the stuff in between.

My background is in marketing, and most of what I make sits between marketing and development. That combination came about because the projects I wanted to take on needed both sides, so I learned to build what I was designing.

Recent work includes recruitment websites with live job boards, a logo for an editorial consultancy, a community association site the board maintains themselves, and a few internal tools built to replace manual processes. I work with small businesses and organizations, usually as the only person on the project.

All three run on Squarespace with custom HTML, CSS, and JavaScript throughout, including job boards that pull live postings from an external API so listings stay current on their own.

  • Logo design for an editorial consultancy.

    ClarosBrand design

    Claros is named after an ancient shrine of Apollo in western Turkey, and the client wanted Apollo at the centre of the mark: seated toward the viewer, bare-chested with robes, holding a torch in one hand and a lyre in the other. I drew it in Illustrator as a stamp-style seal in a woodcut-influenced style, with the company name set in spaced capitals around the perimeter, and delivered it in light and dark versions.

  • Website for a residents association.

    Westwood Hills Residents AssociationWeb development

    The association needed one place for events, community updates, resources, and contact, run by board members who don’t write code. I built it on WordPress and hosted it on Hostinger, structured around what residents come to the site looking for. The board has been updating it themselves since launch.

    • wwhra.com ↗

  • Marketing performance dashboard.

    Integrated StaffingData and reporting

    Reporting on marketing performance meant pulling numbers out of Hootsuite, Squarespace Analytics, and GA4 separately, then assembling them by hand every month, and by the time a report was finished the figures were already stale. This dashboard pulls all three sources through a Google Apps Script endpoint into Google Sheets and renders them with Chart.js, so social performance, website analytics, and quarter-over-quarter movement are available at any point in the month.

  • Personal budgeting app.

    Personal projectProduct

    Allowance tracks how much is left to spend in a given month. Users log income and expenses, set budgets by category, and watch the remaining balance update as they spend. It’s a React and Supabase progressive web app, so it installs on a phone and runs like a native app off a single web codebase, and row-level security keeps each account’s data isolated.

    • allowance-flame.vercel.app ↗

  • Job monitoring tool for recruiters.

    Integrated Staffing GroupAutomation

    Recruitment consultants had no way of knowing when an existing client posted a job on a public board, so they often found out weeks late or not at all. This tool watches Job Bank, LinkedIn, and Adzuna on a schedule, matches new postings against the client list, and sends the right consultant a Slack alert plus a morning digest. Company names are written differently on every board, so matches are confidence-scored using normalisation logic. It runs on a Python scraping pipeline behind a Supabase-backed dashboard the team shares.
